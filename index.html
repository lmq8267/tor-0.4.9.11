Tor 0.4.9.11 静态编译版

完全静态链接，无任何动态库依赖，直接解压运行。支持 SOCKS5 用户名指定出口国家。

静态编译 OpenSSL 3.0.15 14 个平台 musl libc

功能特性

完全静态编译

使用 musl libc 静态链接，无任何动态库依赖，解压即用

按国家出口

SocksExitByUser 功能：通过 SOCKS5 用户名指定出口国家

多平台支持

不确定架构？在 Linux/OpenWrt 上执行 uname -m 查看 CPU 架构。Windows x64 系统选 x86_64-pc-windows，32 位选 i686-pc-windows。

Linux 运行教程

1

查看架构并下载

bash
# 查看架构
uname -m

# 根据输出选择对应的包下载（以 x86_64 为例）
curl -fLkO https://github.com/lmq8267/tor-0.4.9.11/releases/download/2026-07-20/tor-x86_64-linux-musl.tar.gz
mkdir -p tor-bin && cd tor-bin
tar -xzf ../tor-x86_64-linux-musl.tar.gz
ls -l
如果无法访问 GitHub，可在其他设备下载后通过 scp 传输到目标机器。
2

生成控制端口密码哈希

bash
cd tor-bin
chmod +x tor

# 替换为你自己的密码，这里只是示例
./tor --hash-password "my_secret_password"
# 输出类似：16:ABCDEF1234567890ABCDEF1234567890ABCDEF1234567890ABCDEF1234567890
# 将此哈希值记录下来，填入下方 torrc 的 HashedControlPassword 一行
3

创建配置文件

将下方「完整配置」中的 torrc 内容复制保存为 torrc 文件，替换 HashedControlPassword 为上一步生成的哈希值。

bash
# 精简快速启动（常用国家，适合日常使用）
cat > torrc <<'EOF'
SocksPort 9050
ControlPort 9051
HashedControlPassword 替换为你的哈希值

SocksExitByUser 1
# 注意：SocksExitUserMap 是 CSV 类型，所有映射必须写在同一行用逗号分隔！
# 多行重复写法只会保留最后一行（其余被忽略），导致其它国家全部失效
SocksExitUserMap "us={us},de={de},jp={jp},sg={sg},gb={gb},fr={fr},kr={kr},nl={nl},au={au},ca={ca},hk={hk},tw={tw},ru={ru},in={in},br={br}"

DataDirectory ./data
GeoIPFile ./geoip
GeoIPv6File ./geoip6
Log notice stdout
EOF
如需全部国家出口映射，请复制页面下方「完整配置」或「全量国家映射」中的内容。
4

启动 Tor

bash
# 创建数据目录并启动
mkdir -p data
./tor -f ./torrc

# 后台运行（daemon 模式）
# 注意：RunAsDaemon 不能与 torrc 中的相对路径（./data 等）共存，
# 否则报 "RunAsDaemon is not compatible with relative paths" 直接退出。
# 必须用绝对路径在命令行覆盖，例如：
./tor -f ./torrc --RunAsDaemon 1 --DataDirectory "$PWD/data" --GeoIPFile "$PWD/geoip" --GeoIPv6File "$PWD/geoip6"
5

验证是否正常工作

bash
# 通过美国出口访问
curl -x "socks5h://us:my_secret_password@127.0.0.1:9050" https://check.torproject.org/api/ip

# 通过日本出口访问
curl -x "socks5h://jp:my_secret_password@127.0.0.1:9050" https://myip.ipip.net

# 通过德国出口访问
curl -x "socks5h://de:my_secret_password@127.0.0.1:9050" https://myip.ipip.net

可选：systemd 开机自启

bash
# 复制程序到系统目录
sudo cp tor /usr/local/bin/
sudo cp geoip geoip6 /etc/tor/
sudo cp torrc /etc/tor/torrc

# 创建 systemd 服务文件
sudo tee /etc/systemd/system/tor.service >/dev/null <<'EOF'
[Unit]
Description=Tor Proxy Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/tor -f /etc/tor/torrc
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

# 启动并设置开机自启
sudo systemctl daemon-reload
sudo systemctl enable --now tor
sudo systemctl status tor

OpenWrt 运行教程

OpenWrt 使用 BusyBox ash shell，不支持 bash 特性。本教程中的命令均兼容 ash。建议使用 sh 或 ash 执行脚本，不要用 bash。
1

确认路由器架构

通过 SSH 登录 OpenWrt 路由器后执行：

ash
uname -m
uname -m 输出对应下载包常见设备
mips 或 mipseltor-mipsel-linux-muslMT7620/MT7621 路由器
armv7ltor-armv7-linux-musleabihf树莓派、多数 ARM 路由器
aarch64tor-aarch64-linux-musl新款 ARM64 路由器
x86_64tor-x86_64-linux-muslx86 软路由
armv5l / armv6ltor-arm-linux-musleabihf旧款 ARM 路由器
2

上传程序到路由器

在电脑上先下载对应包并解压，然后将 tor 程序上传到路由器：

bash（电脑端操作）
# 在电脑上解压后找到 tor 二进制文件
tar -xzf tor-mipsel-linux-musl.tar.gz

# 通过 scp 上传到路由器（替换为你的路由器 IP 和密码）
scp tor root@192.168.1.1:/tmp/

# 也可以在路由器上直接用 wget 下载（如果路由器能访问 GitHub）
ssh root@192.168.1.1 "wget -O /tmp/tor https://github.com/lmq8267/tor-0.4.9.11/releases/download/2026-07-20/tor-mipsel-linux-musl/tor"
3

在路由器上配置并启动

ash（路由器端操作）
# === 在路由器上通过 SSH 执行 ===

# 1. 创建 Tor 目录
mkdir -p /etc/tor/data

# 2. 移动程序到系统目录
cp /tmp/tor /usr/bin/tor
chmod 755 /usr/bin/tor

# 3. 下载 GeoIP 数据文件（如路由器能访问 GitHub）
# 如果无法访问，可从电脑端 scp 上传
wget -O /etc/tor/geoip https://raw.githubusercontent.com/lmq8267/tor-0.4.9.11/master/src/config/geoip 2>/dev/null || echo "请从电脑上传 geoip 文件"
wget -O /etc/tor/geoip6 https://raw.githubusercontent.com/lmq8267/tor-0.4.9.11/master/src/config/geoip6 2>/dev/null || echo "请从电脑上传 geoip6 文件"

然后生成密码哈希并创建配置文件：

ash
# 4. 生成密码哈希
/usr/bin/tor --hash-password "my_secret_password"
# 记录输出的哈希值，填入下方 torrc

# 5. 创建配置文件（监听 127.0.0.1 仅本机可用）
cat > /etc/tor/torrc <<'EOF'
SocksPort 9050
ControlPort 9051
HashedControlPassword 替换为你的哈希值

SocksExitByUser 1
# 注意：SocksExitUserMap 是 CSV 类型，所有映射必须写在同一行用逗号分隔！
# 多行重复写法只会保留最后一行（其余被忽略），导致其它国家全部失效
SocksExitUserMap "us={us},de={de},jp={jp},sg={sg},gb={gb},fr={fr},kr={kr},nl={nl},au={au},ca={ca},hk={hk},tw={tw},ru={ru},in={in},br={br}"

DataDirectory /etc/tor/data
GeoIPFile /etc/tor/geoip
GeoIPv6File /etc/tor/geoip6
Log notice stdout
EOF

# 6. 启动 Tor（前台测试）
tor -f /etc/tor/torrc

# 7. 或后台运行
tor -f /etc/tor/torrc --RunAsDaemon 1

# 8. 停止后台 Tor
killall tor
4

如需对外提供服务（其他设备连接）

将 SocksPort 改为监听所有地址，并开放防火墙端口：

ash
# 修改 SocksPort 为外部可访问
sed -i 's/SocksPort 9050/SocksPort 0.0.0.0:9050/' /etc/tor/torrc

# 开放防火墙端口（OpenWrt 标准命令）
uci add firewall rule
uci set firewall.@rule[-1].name='allow-tor'
uci set firewall.@rule[-1].src='lan'
uci set firewall.@rule[-1].dest_port='9050'
uci set firewall.@rule[-1].proto='tcp'
uci set firewall.@rule[-1].target='ACCEPT'
uci commit firewall
/etc/init.d/firewall restart

可选：开机自启动（procd 服务）

ash
# 创建 procd 服务脚本
cat > /etc/init.d/tor <<'INITEOF'
#!/bin/sh /etc/rc.common

START=99
STOP=10

USE_PROCD=1

start_service() {
    procd_open_instance
    procd_set_param command /usr/bin/tor -f /etc/tor/torrc
    procd_set_param respawn 3600 5 5
    procd_set_param stdout 1
    procd_set_param stderr 1
    procd_close_instance
}
# 注意：不要自定义 stop_service() 去 killall tor，
# 那样会提前杀掉 procd 自身管理的进程、干扰停止流程。
# procd 会自动停止它启动的 Tor 实例。
INITEOF

chmod 755 /etc/init.d/tor

# 启动服务
/etc/init.d/tor start

# 设置开机自启
/etc/init.d/tor enable

# 管理服务
/etc/init.d/tor stop
/etc/init.d/tor restart
/etc/init.d/tor status

可选：配合第三方客户端（OpenClash / PassWall / SSR-Plus 等）

如果路由器已安装 OpenClash 等代理工具，可将 Tor 作为上游代理使用，或将 Tor 的 SocksPort 填入相应客户端的节点配置中。Tor 监听 127.0.0.1:9050 时，客户端填入 SOCKS5://127.0.0.1:9050 即可。

完整配置文件（一键复制）

以下是一份包含 全部国家出口映射 的完整 torrc 配置文件。适用于 Linux / OpenWrt / Windows 通用。复制后替换 HashedControlPassword 为你的密码哈希值，并根据运行平台调整 DataDirectory、GeoIPFile、GeoIPv6File 的路径。

torrc - 完整版（含全部国家出口映射）
# ============================================================
# Tor 0.4.9.11 完整配置（中文注释版）
# 含全部国家 SOCKS5 用户名出口映射
# 适用于 Linux / OpenWrt / Windows 通用
# ============================================================

# ---------- 基本代理 ----------
SocksPort 9050
# 若需对外提供服务，改为：SocksPort 0.0.0.0:9050

# ---------- 数据目录 ----------
DataDirectory ./data
# OpenWrt 路径示例：DataDirectory /etc/tor/data
# Windows 路径示例：DataDirectory .\data

GeoIPFile ./geoip
GeoIPv6File ./geoip6

# ---------- 日志 ----------
Log notice stdout
# 或写文件：Log notice file ./data/notices.log

# ---------- 控制端口 ----------
ControlPort 9051
# 替换为 --hash-password 生成的哈希值
HashedControlPassword 替换为你的哈希值

# ============================================================
#  ★ 按 SOCKS5 用户名指定出口国家 ★
#  格式：SocksExitUserMap "用户名={国家代码},用户名2={国家代码2},..."
#  用户名 = SOCKS5 认证时传入的用户名（任意字符串）
#  国家代码 = ISO 3166-1 alpha-2 小写两字母

#   若写成多行，Tor 只保留最后一行，其它全部失效。
# ============================================================
SocksExitByUser 1

# ---- 全部国家出口映射（单行 CSV，一次生效全部国家）----
SocksExitUserMap "cn={cn},jp={jp},kr={kr},hk={hk},tw={tw},mo={mo},sg={sg},my={my},th={th},vn={vn},ph={ph},id={id},kh={kh},la={la},mm={mm},bn={bn},in={in},pk={pk},bd={bd},lk={lk},np={np},bt={bt},mn={mn},kz={kz},uz={uz},de={de},fr={fr},gb={gb},nl={nl},se={se},no={no},dk={dk},fi={fi},ch={ch},at={at},it={it},es={es},pt={pt},be={be},ie={ie},is={is},lu={lu},pl={pl},cz={cz},hu={hu},ro={ro},bg={bg},gr={gr},cy={cy},mt={mt},si={si},hr={hr},sk={sk},lt={lt},lv={lv},ee={ee},rs={rs},ua={ua},ru={ru},by={by},md={md},tr={tr},us={us},ca={ca},mx={mx},br={br},ar={ar},cl={cl},co={co},pe={pe},ve={ve},uy={uy},ec={ec},bo={bo},py={py},pa={pa},cr={cr},cu={cu},do={do},pr={pr},au={au},nz={nz},fj={fj},il={il},sa={sa},ae={ae},qa={qa},kw={kw},om={om},bh={bh},jo={jo},lb={lb},iq={iq},ir={ir},az={az},am={am},ge={ge},za={za},ng={ng},eg={eg},ma={ma},ke={ke},gh={gh},tz={tz},et={et},cm={cm},ci={ci},sn={sn},cd={cd},ug={ug},zw={zw},mz={mz},dz={dz},tn={tn},na={na},bw={bw},mw={mw},mg={mg},rw={rw}"

GeoIPv6FileIPv6 国家数据库文件路径编译时内置
Log日志输出目标，支持 stdout 或 file 路径无

BandwidthRate平均带宽限制，格式 NKB/NMB/NGB无限制
BandwidthBurst突发带宽限制无限制
HTTPSProxy上游 HTTP 代理，格式 host:port（需外网代理时使用）无

go
package main

import (
    "fmt"
    "net/http"
    "golang.org/x/net/proxy"
)

func main() {
    // 通过德国出口
    dialer, err := proxy.SOCKS5("tcp", "127.0.0.1:9050",
        &proxy.Auth{User: "de", Password: "my_secret_password"},
        proxy.Direct,
    )
    if err != nil {
        panic(err)
    }
    client := &http.Client{Transport: &http.Transport{DialContext: dialer.Dial}}
    resp, _ := client.Get("https://myip.ipip.net")
    defer resp.Body.Close()
    buf := make([]byte, 4096)
    n, _ := resp.Body.Read(buf)
    fmt.Println(string(buf[:n]))
}

不指定国家（需要先关闭 SocksExitByUser）

bash
# 注意：启用 SocksExitByUser 后，未提供用户名的连接会被【直接拒绝】
# （Tor 日志：SOCKS stream has no username; rejecting per SocksExitByUser）
# 不存在"无认证走随机出口"。若确实不需要按国家出口，请把 torrc 里的
# SocksExitByUser 1 改为 SocksExitByUser 0（或删除 SocksExitByUser 与
# SocksExitUserMap 两行）后重启 Tor，此时才走随机出口：
curl --socks5-hostname 127.0.0.1:9050 https://check.torproject.org/api/ip
源码实现（src/core/or/circuituse.c）：SocksExitByUser 1 时，无 SOCKS5 用户名 → 拒绝；用户名有映射 → 固定该国出口（chosen_exit_optional=0 不回退）；用户名无映射或无可用出口 → 拒绝。密码不会被 Tor 校验。

已验证：使用「在线配置生成器」生成的配置可正常运行，出口有效（非所有国家出口可用）。

本定制版 Tor 与 在线配置生成器 是同一套字段体系（均由源码 option_table 生成），并已通过本仓库 GitHub Actions 自动化全量测试 与手工实测（日本、德国、英国、美国等出口均验证通过）。如果你打开配置生成器生成并运行测试后发现“似乎用不了”，别慌，可先照着下面的自测脚本跑一遍，确认你的运行环境能正常连上 Tor 网络。

1

一键自测脚本（Linux x86_64，整段复制到终端执行）

bash
#!/usr/bin/env bash
# Tor 0.4.9.11 定制版 · 按 SOCKS5 用户名指定出口国家 · 完整自测
set -euo pipefail

# 1) 下载静态编译版（其它平台换成对应包名即可）
curl -fL -o tor.tar.gz \
  https://github.com/lmq8267/tor-0.4.9.11/releases/latest/download/tor-x86_64-linux-musl.tar.gz
tar -xzf tor.tar.gz
chmod +x tor

# 2) 启动：用户名 = 国家代码（此处 jp=日本、de=德国）
mkdir -p /tmp/tordata
./tor --SocksPort 127.0.0.1:9050 \
      --SocksExitByUser 1 \
      --SocksExitUserMap "jp={jp},de={de}" \
      --DataDirectory /tmp/tordata \
      --GeoIPFile ./geoip --GeoIPv6File ./geoip6 \
      --Log "notice stdout" > /tmp/tor.log 2>&1 &

# 3) 等待 Tor 引导完成（Bootstrapped 100%）
for i in $(seq 1 90); do
  if grep -q "Bootstrapped 100" /tmp/tor.log 2>/dev/null; then break; fi
  sleep 2
done
sleep 20   # 等出口描述稳定，避免“暂缺出口”误报

# 4) 分别用 jp / de 用户名验证出口
for cc in jp de; do
  ip=$(curl -sS -m 20 -x "socks5h://${cc}:anypwd@127.0.0.1:9050" https://api.ipify.org)
  geo=$(curl -sS -m 10 "https://ipwho.is/${ip}")
  country=$(printf '%s' "$geo" | grep -o '"country":"[^"]*"' | head -1 | cut -d'"' -f4)
  echo "[${cc}] 出口 IP ${ip} → ${country}"
done

# 5) 清理
pkill -f "tor --SocksPort" || true

常见问题

检查网络连接是否正常。如果需要代理才能访问外网，在 torrc 中添加上游代理配置：

torrc
HTTPSProxy 127.0.0.1:8080

支持 HTTPSProxy、HTTPProxy、Socks4Proxy、Socks5Proxy 等格式。

启动后等待连接完成（看到 100% bootstrapped），然后：

bash
# 未启用 SocksExitByUser（或已设为 0）时可直接验证：
curl --socks5-hostname 127.0.0.1:9050 https://check.torproject.org/api/ip

# 启用了 SocksExitByUser 1 时，必须带 SOCKS5 认证，否则会被拒绝：
curl -x "socks5h://us:my_secret_password@127.0.0.1:9050" https://check.torproject.org/api/ip

# 使用 tor-resolve 工具测试 DNS
./tor-resolve check.torproject.org

连接会被 拒绝。启用 SocksExitByUser 1 后，客户端必须使用在 SocksExitUserMap 中有映射的用户名并正确传递 SOCKS5 认证（curl 用 -x socks5h://用户名:密码@127.0.0.1:9050 或 -U 用户名:密码）；不提供用户名同样会被拒绝（authentication required），不存在"随机出口"。

可以。routerset 语法支持多国映射，格式为 "用户名={国家1,国家2,...}"，例如：

torrc
SocksExitUserMap "asia={jp,kr,sg,hk,tw,my,th},europe={de,fr,gb,nl},americas={us,ca,br}"

Tor 会在这些国家中随机选择出口节点。

部分国家在 Tor 网络中没有或极少出口节点，使用这些国家可能导致电路构建失败或超时。常见的包括：中国大陆（cn）、朝鲜（kp）、白俄罗斯（by）、土库曼斯坦（tm）等。

建议：不要设置 StrictNodes 1，这样在某个国家没有可用出口节点时 Tor 可能回落到其他节点。

torrc 中的 HashedControlPassword 填写的是 --hash-password 生成的哈希值（如 16:ABCDEF...），而客户端程序（curl、Python 等）填写的是明文密码。Tor 会在验证时自动比对。
